# Eligibility

## Timeline

Project work began **1 September 2026**, under the ETHGlobal staff ruling permitting work to start
ahead of the event window, with commits beginning **4 September 2026**.

Work done between 1–3 September (dependency verification and initial scaffold) is committed as a
sequence of real, meaningful commits from the 4th onward. **No commit is backdated** and no history
is fabricated. The commit dates are the dates the commits were made; the prompt log in
[`spec/PROMPTS.md`](spec/PROMPTS.md) records when the underlying work actually happened.

## Version control

Committed continuously in small, meaningful increments across the event, per ETHGlobal's
version-control requirement. No single-commit dumps.

## Track

Start Fresh (Classic / From Scratch). This project is net-new — no code predates 1 September 2026.
For The Graph's AI Tooling prize, the **From Scratch** pool is selected.

## Open source dependencies

Public starter kits and open-source libraries are used throughout, as explicitly permitted.
Principal dependencies: `@x402/*` (x402 Foundation), `@ensdomains/contracts-v2`, `@hiero-ledger/sdk`.
